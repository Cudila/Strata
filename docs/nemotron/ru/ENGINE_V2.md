# strata-nemotron: движок v2 — decode 21 → 150–190 т/с (2026-10-18)

Цель: догнать по скорости qwen3.8-flash-next в Strata (на этой машине 156–270 т/с decode с MTP).

## Итог (RTX 5090, 14700KF, DDR5-5200, NVFP4-эксперты, сэмплинг temp 1.0)

| Режим | decode, т/с |
|---|---:|
| v1 | 21 |
| v2 без спекуляции (`--skip-w 0.4`, `--prefetch 0`) | 105–110 |
| v2 + MTP (`--spec 5 --spec-min-p 0.8`), бенч, 4 промпта × 500 токенов | 172–186 |
| слот llama-swap, 1500 токенов | 152–191 |

Качество: попарный ΔNLL decode-пути (wikitext, 8 × 1024, 4088 токенов) при `--skip-w 0.4` = +0.0046 ± 0.0027
(PPL ×1.005). Спекуляция точна: при greedy без пропусков вывод побитно совпадает с обычным decode (300/300).

## Что сделано (в порядке вклада)

1. **Пропуск промахов кэша по весу маршрутизации** (`--skip-w τ`): эксперт, которого нет в VRAM и чей вес во всех
   строках окна < τ, не копируется (нулевой эксперт). Промахи — это в основном редкие эксперты с малым весом,
   поэтому цена мала. Пропуск по рангу (как ROUTE_TAIL_SKIP в Strata) при той же скорости хуже по качеству.
   τ = 0.3/0.4/0.5: PPL ×1.0054/×1.0046/×1.0044 (в пределах 2σ); скорость спекуляции 136→150→ до 180.
2. **MTP-спекуляция** (`spec_step`): черновики блоком MTP (blk.88: eh_proj, NoPE-attention, MoE на 512
   резидентных NVFP4-экспертов, LayerNorm-голова, общий lm_head; своя KV), окно проверки ≤ 8 строк через
   decode-путь, откат Mamba: снимок состояний + повтор conv/scan для принятых строк из сохранённых in_proj-строк;
   KV MTP дописывается истинными h. Сэмплинг точный: токен строки тянется из распределения основной модели,
   черновик принимается при совпадении. Цепочка обрывается на черновике с вероятностью MTP < `--spec-min-p`.
   Проба greedy: из 4 черновиков в среднем 2.5–3.25 принимаются.
3. **Плиточные tensor-core GEMV** (`nemo_tiled_*`): плотные NVFP4/Q8_0/BF16 переупакованы при загрузке так, что
   линия читает ровно свои B-фрагменты mma.m16n8k16; M = 1..8 стоит почти как M = 1 (in_proj 36 → 38 мкс при M 1 → 8,
   CUDA-core было 361). Строка не зависит от M → окно проверки = decode побитно.
4. Быстрые CUDA-core GEMV (`nemo_gemv`: вход в shared с паддингом против bank conflicts, grid-stride, LUT в shared,
   wide-вариант для матриц с малым числом строк), эксперты пачкой (`nemo_gemv_many`).
5. Кэш: copy-stream, сначала считаются эксперты-попадания, LFU с затуханием 0.97 (`--evict lfu`, −7% промахов
   против LRU по трассе; Belady — −55%, недостижим).
6. Предзагрузка (роутер следующего слоя на текущем остатке) помогала без пропусков, но с `--skip-w` вредит вдвое —
   выключена (`--prefetch 0`).

## Проверено и отброшено

- Готовые 2-битные эксперты AtomicChat AD-Q2_0_L (ядра IQ3_XXS/IQ4_XS/IQ4_NL/Q2_0 есть, `--experts-gguf`):
  PPL +8–12% против NVFP4; после пропуска по весу NVFP4 ещё и быстрее. Не используются.
- Кэш экспертов MTP меньше 512 с пропуском промахов: доля принятых черновиков падает сильнее, чем растёт кэш.
- PCIe 5 на этой машине даёт 41 ГБ/с при любом размере копии (замер) — размер/слияние копий не помогает.

## Ключи движка

`--spec N --spec-min-p p --skip-w τ --tail-skip R --prefetch 0|1 --evict lru|lfu --mtp-slots N --experts-gguf F`;
бенч: `--bench a.txt,b.txt --spec-list 4,5,6 --min-p-list 0.7,0.8 --temp 1.0`, `--mtp-probe N`, `--ppl-decode --ll-dump F`.
Тесты: `nemo_gemm_parity` (вкл. tc/tiled), `nemo_iq_parity`, mamba/attn/moe parity — PASS.
